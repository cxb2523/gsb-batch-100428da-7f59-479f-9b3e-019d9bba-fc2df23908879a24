
Этот код проверялся на python-3.8.10-amd64
<br> Это древняя версия питона, и она должна запуститься даже на Windows 7 (вроде как).
<br>

Перед запуском нужно установить недостающие либы:

```
python -m pip install -r requirements.txt
```

Для запуска получения данных через запуск утилиты командной строки нужно выполнить:
```
python scrape_ozon_cli.py parameters.json
```
Файл parameters.json берется из подпапки results, если у файла не указаны абсолютные пути.
И в этот же каталог сохраняется результат.

Для запуска GUI утилиты нужно выполнить
```
python scrape_ozon_gui.py
```

### Асинхронный режим (ожидание длинных запросов)

Клиенты всегда добавляют в запрос поле `asynchronously`. Если сервер отвечает
`poll_token`-ом, клиент опрашивает его по тому же адресу, который был получен
с GitHub один раз (адрес между опросами не перезапрашивается), пока не получит
готовые данные или не истечёт общий лимит ожидания.

Лимит по умолчанию - 10 минут, интервал опроса - 10 секунд. Изменить их можно:

* в параметрах CLI: `"poll_timeout_sec": 1800`, `"poll_interval_sec": 10`;
* переменными окружения `OZON_POLL_TIMEOUT` и `OZON_POLL_INTERVAL`;
* в GUI: поле «Лимит ожидания, сек» (пустое - значение по умолчанию).

При таймауте или ошибке CLI пишет в `dest_filename` JSON вида
`{"ошибка": "..."}` с понятной причиной, а не текст `poll_token`.
GUI показывает результат в отдельной вкладке «Таймаут» или «Ошибка».

Адрес сервиса можно временно переопределить переменной `OZON_SERVICE_URL`
(полезно для локальной проверки без обращения к GitHub).

Тесты офлайновые, используют локальный фейковый сервис:
```
python -m pytest
```

При желании можно скомпилировать в выполняемые файлы, чтобы не нужно было возиться с запуском python.<br>
Для этого сначала нужно установить pyinstaller
```
python -m pip install pyinstaller
```
и затем запустить
```
make_clients.bat
```
В результате получите файлы `scrape_ozon_cli.exe` и `scrape_ozon_gui.exe`.
