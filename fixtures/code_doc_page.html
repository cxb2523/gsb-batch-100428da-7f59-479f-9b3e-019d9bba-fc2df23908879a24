API Reference

Phantombot exposes a RESTful API for crawling and querying web data.

Endpoints

MethodPathDescription
POST/crawlStart a new crawl job
POST/queryQuery extracted entities
POST/searchSemantic vector search
GET/entity/{id}Get entity by ID

Authentication

Pass your API key in the X-API-Key header:

curl -H "X-API-Key: your-key" https://api.example.com/query

Example: Start a Crawl

import requests

resp = requests.post("https://api.example.com/crawl", json={
    "url": "https://example.com",
    "max_depth": 3,
})
print(resp.json())

Rate Limits

The API is rate-limited to 100 requests per minute. If you exceed this limit, you will receive a 429 response.
