# 本地验证样例

两个样例都是普通的 UTF-8 文本脚本，可用记事本打开编辑，沿用“火小兔/机关区读取脚本文件”的原有方式运行。
运行后会在本目录生成 `运行记录_<脚本文件名>` 控制目录，里面有实时状态与结束报告。

## 1. 失败与继续.秘籍 —— 单条失败不中断
包含 4 条正常命令与 1 条必然失败的命令（调用了不存在的功能）。
预期：第 3 条记录为失败（含序号、原文、错误信息），第 4、5 条照常执行；
结束汇总为“成功 4 条、失败 1 条”，报告见 `运行记录_失败与继续.秘籍/执行报告.txt`。

## 2. 暂停继续演示.秘籍 —— 暂停/继续
脚本中有两处 `等2秒`，留出操作窗口：
1. 运行脚本，留意控制台打印的控制目录路径；
2. 在控制目录中新建空文件 `暂停.信号`（资源管理器右键“新建→文本文档”后改名即可），脚本随即暂停；
3. 打开 `运行状态.json` 可核对当前进度；暂停期间移动鼠标、观察屏幕，不会出现任何新的键鼠动作；
4. 新建空文件 `继续.信号`，脚本从下一条命令接着执行，已完成的命令不会重跑；
5. 新建 `停止.信号` 可提前结束脚本。
若启用了热键（入口脚本默认启用），也可直接按 F7 暂停 / F8 继续 / F9 停止。

## 无副作用的自动化验证
`../tests/test_fbidp.py` 使用假的键鼠/剪贴板/子进程模块运行全部验证，
不会触发任何真实鼠标键盘动作、不联网、不使用真实凭据：

```cmd
python -I -X utf8 ../tests/test_fbidp.py
```

`../tests/run_sample_safely.py` 用同样的假模块直接运行本目录的样例并打印报告：

```cmd
python -I -X utf8 ../tests/run_sample_safely.py 失败与继续.秘籍
```
